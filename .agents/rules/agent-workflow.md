# Flujo de Trabajo con Git
1. **Pull Obligatorio:** Antes de comenzar a realizar cualquier cambio en el código o analizar archivos para una nueva tarea, SIEMPRE debes ejecutar `git pull origin main` (o la rama correspondiente) para asegurar que tienes la versión más reciente del repositorio.
2. **Push Obligatorio:** Inmediatamente después de completar una tarea y verificar que los cambios son correctos, SIEMPRE debes realizar un `git commit` y luego un `git push` al repositorio remoto.

# Uso de Skills
1. **Evaluación de Contexto:** Antes de proceder con una solución, debes considerar activamente el contexto del proyecto (en este caso, un Portal Académico LIATER).
2. **Uso Riguroso:** Revisa la lista de skills disponibles. Si el contexto lo permite y una skill es útil para el desarrollo del portal académico (ej. diseño de UI/UX, arquitectura de base de datos, etc.), debes utilizarla de manera rigurosa y justificada. No apliques skills genéricas sin adaptarlas a las necesidades específicas del proyecto.
