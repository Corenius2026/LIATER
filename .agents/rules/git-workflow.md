# Regla: Flujo de Trabajo con Git

Siempre que realices cambios en el código de este repositorio, debes seguir este flujo de trabajo obligatoriamente:

1. **Antes de hacer cualquier cambio**, ejecuta `git pull` para asegurarte de tener la última versión del repositorio.
2. **Después de realizar y verificar los cambios**, ejecuta los comandos necesarios para hacer commit y push al repositorio (`git add .`, `git commit -m "..."`, y `git push`).

Esta regla asegura que el repositorio siempre esté sincronizado.
