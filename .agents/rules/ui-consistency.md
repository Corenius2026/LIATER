# Regla: Consistencia de UI y Paleta de Colores

Al realizar modificaciones en los estilos, componentes o páginas de este proyecto, debes adherirte estrictamente a la siguiente paleta de colores ("Black and Gold Elegance"):

* **Blanco / Texto claro:** `#FFFFFF`
* **Gris Claro / Fondos secundarios:** `#E5E5E5`
* **Dorado / Acentos y botones:** `#FCA311`
* **Azul Marino Oscuro / Fondos principales:** `#14213D`
* **Negro / Texto oscuro o fondos profundos:** `#000000`

**Directivas:**
1. **Respetar la Paleta de Colores:** Siempre utiliza estos códigos hexadecimales exactos en los estilos y variables CSS.
2. **No introducir colores disonantes:** Evita agregar colores arbitrarios que rompan con este diseño premium. Si requieres efectos visuales como *glassmorphism*, utiliza variaciones de opacidad de estos mismos colores.
